# Site Visit Rules

## 路线原则

- 每半天通常 3–6 个点；
- 同一楼宇/同一商圈优先一起看；
- `verify_first` 候选先电话/在线确认，再占用踩点时段；
- 没有实时导航数据时，只做区域分组和粗排序，不给伪精确交通分钟；
- 有坐标时脚本可做近邻顺序，最终仍需用地图/导航核对。

## 商铺现场核验

- 门头宽度、展示面、遮挡；
- 工作日/周末、不同时段人流；
- 车流、停车、装卸；
- 上下水、排烟路径、燃气/明火、电量；
- 卫生间、垃圾清运、外摆；
- 营业时间、招牌权限、物业业态限制；
- 转让费、进场费、装修恢复；
- 邻铺、同层/同街空置率；
- 门前台阶、无障碍、消防通道。

## 写字楼现场核验

- 地铁出口到楼门实测；
- 大堂与访客管理；
- 电梯高峰等待；
- 采光、噪音、层高、柱网、窗户；
- 使用效率与工位/会议室布局；
- 空调时段、加班空调费；
- 停车、快递、外卖、午餐；
- 装修交付、网络、注册；
- 物业费、税费及其他固定成本。

## 统一拍照清单

外立面、入口、门牌、室内四角、窗外视野、公共区域、电梯厅、卫生间、消防/设备点、门头/临街面、上下水/排烟点位。每张用户现场照片建议带候选 ID 和时间，后续可回填为 `user_photo`。
