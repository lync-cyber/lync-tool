# Scoring Rules

## 两个分数必须分开

`fit_score` 回答“适不适合用户”；`confidence_score` 回答“信息有多可信”。低价不能直接提高 confidence。

## 默认 Fit 权重

- 价格/综合成本：25
- 面积/空间适配：15
- 区位/交通：20
- 使用/经营条件：20
- 楼宇/物业品质：10
- 入驻/租期/装修执行便利：10

商铺应提高经营条件、展示面、人流和业态适配的权重；办公应提高交通、综合成本、空间效率和楼宇品质。

## Confidence 的主要证据

加分：

- 高质量直接来源；
- 两个或以上真正独立来源；
- 具体单元信息；
- 清晰的面积与价格口径；
- 当前更新时间；
- 项目/业主/物业级证据；
- V2/V3 明确核验。

减分：

- 极低价且无解释；
- 跨来源价格冲突；
- 无房号、无具体楼层；
- 页面长期不更新；
- “刚租掉后转推更贵房源”等行为证据；
- 图片与项目冲突；
- 单来源 V0。

## 默认门槛

- `confidence_score < 45`：只能 `verify_first`；
- 低价 ≥30% 且无解释：不得直接进入前三；
- 关键硬条件未知：`verify_first`；
- 硬条件明确失败：`excluded`；
- V0 单来源原则上不能进入最终 Top 5。
- 仅由 `broad_discovery`/`lead_only` 支撑且没有独立交叉证据：标记 `supplementary_lead`，不占主候选表。
- 用户选择 `fixed_monthly_cost` 时，成本不完整：预算硬条件为未知，进入 `verify_first`；不得退回裸租金假装满足。

`decision_score = 0.75 × fit_score + 0.25 × confidence_score` 只用于同一门槛层内排序。门槛优先于加权分。

来源角色和任务级优先级由 LLM 按 `source_plan.json` 决定；脚本只读取 registry 先验并执行门槛，不根据广告数量自行学习平台可靠度。
