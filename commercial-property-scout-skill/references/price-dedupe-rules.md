# Price & Deduplication Rules

## 价格口径

租赁默认同时维护：元/㎡/天、月租总额、物业费、税费、其他固定费用和固定月总成本。默认月租换算基于 `365/12` 天；平台明确采用 30 天口径时应保留平台原始值和换算说明。

只有物业费口径明确为“每平方米每月”“月总额”或“已含”时才计算固定月总成本。口径不明时保留原始值并标 `partial`，不要猜测单位。水电、营业额提成等变量成本不计入精确固定总额，但应单列风险。

必须显式区分：

- 建筑面积 / 使用面积；
- 含税 / 不含税；
- 含物业费 / 不含物业费；
- 名义租金 / 免租折算后的有效租金；
- 标准价 / 起价 / 补贴价 / 特定资质价；
- 整租 / 分割最小单元；
- 首年优惠 / 全租期平均。

## 可比样本层级

1. 同楼、同类型、相近面积；
2. 同项目不同楼栋；
3. 同商圈、相近等级、面积 ±30%；
4. 同区域同资产类别。

不要把甲级办公与老旧商住楼混为一组；不要把购物中心首层铺与社区底商混为一组。

## 默认异常阈值

- 低 15%–20%：轻度异常；
- 低 20%–30%：明显异常；
- 低 30% 以上：高风险，必须寻找可验证解释。

这些是核验阈值，不是“判假阈值”。

## 自动去重原则

脚本只自动合并强证据重复：

- 同项目 + 同具体单元；
- 同项目/地址 + 同楼层 + 面积非常接近；
- 同项目/地址 + 面积接近 + 完全相同图片来源；

仅“项目相同 + 面积差不多”不够。边界案例写入 `possible_duplicates.json`，由 worker 人工判断。

## 同一广告的价格冲突

跨平台聚合后保留最小值、最大值和中位值。价差 ≥20% 应生成红旗，不能静默选最低价。


## 执行引擎

`detect_price_anomalies.py --engine auto` 在 pandas 可用时优先使用预分组 DataFrame，避免每个候选反复扫描全表；输出语义必须与标准库路径一致。

`dedupe_properties.py --engine auto` 对小数据使用完整比较，默认达到 250 条原始广告后可切换 pandas blocking：按项目/地址/单元/楼层/面积桶/完全相同图片先生成候选对，再执行原有强证据 merge 规则。blocking 只优化“比较谁”，不能降低自动合并门槛。

如果担心大数据 blocking 漏掉边界重复，可对最终高排名项目单独运行 stdlib 完整比较或人工反向核验。
