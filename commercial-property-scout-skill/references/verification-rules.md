# Verification Rules

## V0 — 单来源广告

只有单条广告或同一上游来源的复制，没有独立证据。V0 不能作为高置信 Top 5 的常态。

## V1 — 多来源一致

至少两个真正独立的信息链路对项目、面积、楼层/单元、价格区间等关键字段大体一致。不同账号复制同一中介稿件不算独立来源。

## V2 — 项目级核验

存在项目官网、开发商/业主招商、物业招商、大型代理项目页、政府公开信息等证据，能够确认项目身份、物业用途、招商状态或价格逻辑。

V2 不自动证明第三方广告中的某个具体室号仍可租。

## V3 — 单元级当前确认

必须有当前、具体、可复查的单元级确认，至少覆盖：

- 具体楼栋/楼层/室号或能够唯一定位的单元；
- 当前可租/可售状态；
- 该单元实际报价及报价口径；
- 面积；
- 看房/交付状态或当前确认时间。

V3 不得由脚本根据“多个平台都出现”自动升级。

## 低价核验的必问项

1. 该具体单元今天是否仍在？
2. 报价是否是该单元，而不是同楼起价？
3. 建筑面积还是使用面积？
4. 含税、含物业费与否？
5. 是否有免租、补贴、企业资质、长租、预付等前提？
6. 是否有转让费、进场费、佣金、装修恢复等额外成本？
7. 能否只看这一套，不接受先到现场再换推荐？

## 验证码与登录

遇到 CAPTCHA、滑块、短信、二维码、账号二次验证时：

- 停止自动操作；
- 在 `state.json.captcha_waiting_on` 记录平台、页面和所需人工动作；
- 请用户本人完成；
- 用户完成后继续当前状态；
- 不自动识别、不绕过、不对抗反爬与登录限制。

## 对外联系约束

未经用户明确授权，不代表用户发送消息、提交手机号、预约、议价、出价、签署或承诺。技能可以生成核验话术和问题清单。
