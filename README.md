# lync-tool

个人常用工具与脚本合集，用于沉淀能够在日常开发和设备配置中重复使用的小工具。

## 工具目录

| 工具 | 用途 |
| --- | --- |
| [`codex-dev-setup`](./codex-dev-setup/) | 为 Windows 11 设备提供以 Codex Desktop 为中心的可重复开发环境配置向导。 |

## 使用说明

每个工具均在其目录内维护独立的说明文档、配置和测试。使用前请先阅读对应目录中的 `README.md`，了解前置条件、执行方式与安全注意事项。

## 约定

- 工具应尽可能可重复执行，并明确说明会修改的内容。
- 不提交密钥、令牌、个人凭据或机器特定的敏感配置。
- 新增工具时，请在本 README 的目录中补充用途说明和入口链接。
